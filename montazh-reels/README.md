# Монтажёр Reels для ChatGPT

Инструкция-скилл для урока 4.2 мини-курса NEUROHACKER «7 AI-агентов». С ней ChatGPT в режиме «Work» монтирует из твоей записи с телефона готовое вертикальное видео: заголовок с главным словом, субтитры по словам, переходы и графика по смыслу.

## Как пользоваться

Скопируй инструкцию из конспекта урока 4.2 и отправь её первым сообщением в чат с плагином Remotion. В инструкции есть ссылка на этот файл `SKILL.md`: ChatGPT прочитает подробный стиль сам.

Можно поставить и как скилл: скачай `SKILL.md`, в ChatGPT открой Plugins, Skills, «+», загрузи файл. Дальше в чате режима «Work» пиши: «Смонтируй Reels из моей записи».

Ключей и паролей скилл не требует. Ничего не публикует.

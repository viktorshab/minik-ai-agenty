# Монтажёр Reels для ChatGPT

Инструкция-скилл для урока 4 мини-курса NEUROHACKER «7 AI-агентов». С ней ChatGPT в режиме «Work» монтирует из твоей записи с телефона готовое вертикальное видео: заголовок с главным словом, субтитры по словам, переходы и графика по смыслу.

## Как пользоваться

Скопируй инструкцию из конспекта урока 4 и отправь её первым сообщением в чат с плагином Remotion. В инструкции есть ссылка на этот файл `SKILL.md`: ChatGPT прочитает подробный стиль сам.

Отдельно ставить ничего не нужно: инструкция из конспекта сама ссылается на этот файл.

Ключей и паролей скилл не требует. Ничего не публикует.

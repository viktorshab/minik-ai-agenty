# Личный плагин Apify для ChatGPT

Это заготовка для урока 4.1 мини-курса NEUROHACKER «7 AI-агентов». С ней ChatGPT в браузере сам собирает тебе личный плагин: агент получает из Instagram открытые Reels и их просмотры через твой аккаунт Apify.

Проект неофициальный и не связан с компанией Apify. Он только пересылает запросы ChatGPT на официальный сервер Apify `mcp.apify.com`.

## Как поставить

Ничего скачивать не нужно. Скопируй запрос из конспекта урока 4.1 (шаг «Подключи Apify») и вставь его в новый чат ChatGPT в режиме «Work». Запрос содержит ссылку на эту папку. ChatGPT прочитает инструкцию `AGENT.md`, соберёт сайт на Sites и даст тебе ссылку на страницу ключа.

## Что понадобится

- Платная подписка ChatGPT и ChatGPT в браузере.
- Бесплатный аккаунт на apify.com. На бесплатном тарифе каждый месяц есть кредиты на запуски; сбор 30 Reels стоит несколько центов.
- Ключ Apify: apify.com, слева Settings, вкладка API & Integrations, Personal API token.

## Где вводится ключ

Только на странице твоего плагина, в поле «Ключ Apify». Не в чат. Сервер проверяет ключ в Apify и хранит его зашифрованным. Сайт открыт только тебе.

Если ты случайно вставил ключ в чат: открой Apify Console, Settings, API & Integrations, удали этот ключ и создай новый. Новый сохрани на странице плагина.

## Как отключить

На странице плагина нажми «Удалить ключ». Чтобы закрыть доступ совсем, удали ключ и в Apify Console.

## Что внутри

| Файл | Зачем |
|---|---|
| `AGENT.md` | Пошаговая инструкция для ChatGPT |
| `src/worker.js` | Сервер: страница ключа и пересылка запросов в Apify |
| `db/schema.sql` | Таблица для зашифрованного ключа |
| `.openai/hosting.json` | Настройки сайта Sites |
| `test/smoke.test.mjs` | Проверка сервера без интернета |

Ключей, паролей и личных данных в этой папке нет.

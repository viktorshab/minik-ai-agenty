# Мини-курс «7 AI-агентов»: файлы к урокам

Это публичные файлы к конспектам мини-курса NEUROHACKER «7 AI-агентов». Ты ничего не скачиваешь и не ставишь руками: в запросе из конспекта уже стоит ссылка, ChatGPT открывает файл и работает по нему. Не открылась ссылка? В конспекте есть короткая версия того же текста, она работает и без ссылки.

## Как ссылаются на файлы

В запросах стоят прямые ссылки вида `https://raw.githubusercontent.com/viktorshab/minik-7-agentov/main/<путь к файлу>`. По такой ссылке ChatGPT получает чистый текст, а не страницу GitHub с меню и кнопками.

## Безопасность

Ключей, паролей и личных данных в репозитории нет. Ключи Apify и других сервисов не вставляй ни в чат, ни в файлы, ни в GitHub: каждый вводит свой ключ только на странице своего плагина. В `.gitignore` перечислены файлы `.env`, ключи и токены, чтобы они не попали в репозиторий случайно.
